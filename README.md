# Credit Scoring Model

## CodeAlpha Machine Learning Internship — Task 1

A Machine Learning-based Credit Scoring system that predicts whether a credit applicant is likely to have **Good Credit** or **Bad Credit** using the German Credit dataset.

The project demonstrates a complete Machine Learning workflow including data loading, data analysis, preprocessing, model training, evaluation, model saving, and prediction.

---

## Project Overview

Credit scoring is used by financial institutions to assess the creditworthiness of applicants.

In this project, a Machine Learning classification model is trained using the **German Credit dataset**. The system analyzes applicant attributes and predicts their credit risk.

### Prediction Classes

- **Good Credit** — Class 0
- **Bad Credit** — Class 1

---

## Dataset

The project uses the **German Credit dataset** from the UCI Machine Learning Repository.

### Dataset Information

- Total records: **1,000**
- Total features: **20**
- Good Credit: **700**
- Bad Credit: **300**
- Missing values: **0**

The dataset contains both numerical and categorical attributes.

### Feature Types

There are:

- 13 categorical features
- 7 numerical features
